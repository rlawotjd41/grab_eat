// 서버 패킷


1. 로그인 / 로그아웃 시스템

로그인 (Login)
-------------------------------------------------------------------------------------------------------
C2S (C2S_Login): 클라이언트가 아이디와 비밀번호를 보내 서버에 로그인을 요청

S2C (S2C_LoginResult): 서버가 로그인 성공 여부(토큰, 에러 코드 등)를 클라이언트에 응답

로그아웃 (Logout)
-------------------------------------------------------------------------------------------------------
C2S (C2S_Logout): 클라이언트가 서버에 로그아웃(접속 종료)을 요청

S2C (S2C_LogoutResult): 서버가 정상 처리되었음을 확인하고 연결을 끊거나 메인 화면으로 이동

-------------------------------------------------------------------------------------------------------
2. 방(Room) / 매칭 시스템

방 생성 / 입장 (Room Enter)
-------------------------------------------------------------------------------------------------------
C2S (C2S_JoinRoom): 클라이언트가 특정 방 코드나 매칭을 요청

S2C (S2C_RoomCode): 서버가 방 코드 및 방 안의 최대 인원, 방 정보 등을 클라이언트에 전달

-------------------------------------------------------------------------------------------------------
3. 게임플레이 (이동 및 동기화)

플레이어 이동 (Player Move)
-------------------------------------------------------------------------------------------------------
C2S (C2S_PlayerMove): 내 플레이어의 실시간 위치/회전 값을 서버로 보냄

S2C (S2C_OtherPlayerInfo): 서버가 내 주변에 있는 다른 플레이어들의 위치 및 상태 정보를 나에게 전달

-------------------------------------------------------------------------------------------------------
4. 아이템 시스템

아이템 상호작용 (획득/사용)
-------------------------------------------------------------------------------------------------------
C2S (C2S_UseItem 또는 C2S_AcquireItem): 클라이언트가 아이템을 줍거나 사용하겠다고 서버에 요청

S2C (S2C_ItemInfo): 서버가 인벤토리 갱신이나 아이템 정보 변경 내역을 클라이언트에 전달

-------------------------------------------------------------------------------------------------------
5. 게임 종료 / 결과 시스템

게임 결과 (Game Result)
-------------------------------------------------------------------------------------------------------
C2S (C2S_RequestGameResult): 클라이언트가 게임 종료 시점의 점수나 결과 처리를 서버에 요청

S2C (S2C_GameResult): 서버가 최종 승패, 점수, 획득 보상 리스트를 클라이언트에 전달하여 결과창을 띄움
